# Token Optimiser product context

## Register

product

## Users

The IML team and course/demo audiences inspect an application workbench for English, Hinglish and Hindi requests. Tushar Saharan owns Compression Studio. The main task on this surface is to compare real compression output with the source prompt before sending a request.

## Product Purpose

Reuse the pinned Research implementation through feature adapters, keep CPU-first execution usable, and make the evidence behind results inspectable. Local outputs, authored examples, historical research results and live answers must remain distinguishable. Historical evaluation scale is not evidence of production capacity.

## Brand Personality

Clear, technical, transparent. The user confirmed a practical course/demo tool in the existing visual style, not a marketing redesign.

## Anti-references

Invented metrics, unsupported scale claims, decorative charts, arbitrary compression algorithms, and interfaces that hide fallbacks or known failures.

## Design Principles

- Inspect the actual source and output side by side.
- Keep local method comparisons separate from historical research evidence.
- Show provenance, requested versus actual methods, and limitations at the point of use.
- Preserve the existing application vocabulary and shared components.
- Prefer fewer honest capabilities over unsupported guarantees.

## Accessibility & Inclusion

The user confirmed keyboard-operable controls, readable Hindi/mixed-script text, text labels alongside highlights, and no automatic animation. Do not make understanding depend on color alone. This context is not a claim of audited WCAG compliance.
